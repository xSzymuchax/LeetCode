# LeetCode

Publiczne repozytorium z rozwiązaniami zadań z [LeetCode](https://leetcode.com/).

Każde zadanie trafia do osobnego katalogu w formacie `numer-slug`, na przykład `0001-two-sum`. W środku jest kod rozwiązania i krótka notatka: pomysł, złożoność czasowa i pamięciowa oraz ewentualne pułapki.

Język rozwiązania zostaje taki, w jakim zadanie zostało zrobione. Nazwa pliku odpowiada nazwie zadania albo konwencji danego języka (`Solution.py`, `Solution.java`, `solution.ts`).
