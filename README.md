# LeetCode

A public repository of solutions to problems from [LeetCode](https://leetcode.com/).

Each problem lives in [`problems`](problems/), in a directory named `number-slug`:

```
problems/0001-two-sum/
├── README.md
└── solutions/
    └── Solution.py
```

A problem `README.md` records the difficulty, a link to the original, a short summary, and the solution's approach, time, and space.

Approaches are indexed in [`approaches`](approaches/). A problem that uses more than one approach is listed in each of those files.
