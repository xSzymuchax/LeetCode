# 35. Search Insert Position

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/search-insert-position/)

Find the index of the target in a sorted array, or the index where it should be inserted.

**Approach:** BinarySearch

- Time: O(log n)
- Space: O(1)
