# 3105. Longest Strictly Increasing or Strictly Decreasing Subarray

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/longest-strictly-increasing-or-strictly-decreasing-subarray/)

Find the length of the longest contiguous subarray that is strictly increasing or strictly decreasing.

**Approach:** LinearScan

- Time: O(n)
- Space: O(1)
