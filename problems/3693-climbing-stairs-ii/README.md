# 3693. Climbing Stairs II

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/climbing-stairs-ii/)

Reach step i with a jump of 1, 2, or 3. The cost is the step cost plus the square of the jump length. Find the minimum.

**Approach:** DynamicProgramming

- Time: O(n)
- Space: O(n)
