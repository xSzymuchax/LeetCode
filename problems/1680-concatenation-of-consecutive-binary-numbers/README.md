# 1680. Concatenation of Consecutive Binary Numbers

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/concatenation-of-consecutive-binary-numbers/)

Concatenate the binary forms of the numbers from 1 to n. Take the result modulo 10^9 + 7.

**Approach:** BitManipulation

- Time: O(n)
- Space: O(1)
