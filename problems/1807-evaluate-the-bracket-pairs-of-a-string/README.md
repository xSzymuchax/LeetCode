# 1807. Evaluate the Bracket Pairs of a String

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/evaluate-the-bracket-pairs-of-a-string/)

Replace each `(key)` with its dictionary value. A missing key becomes a question mark.

**Approach:** HashMap

- Time: O(n + dictionary size)
- Space: O(n + dictionary size)
