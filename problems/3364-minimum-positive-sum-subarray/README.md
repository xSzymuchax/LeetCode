# 3364. Minimum Positive Sum Subarray

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/minimum-positive-sum-subarray/)

Among subarrays whose length is between l and r, find the smallest positive sum. If none exists, return −1.

**Approach:** BruteForce

- Time: O(n · r)
- Space: O(1) excluding the input list
