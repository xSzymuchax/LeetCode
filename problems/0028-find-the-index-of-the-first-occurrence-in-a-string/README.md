# 28. Find the Index of the First Occurrence in a String

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string/)

Find the first index where the needle occurs in the haystack, or -1.

**Approach:** BruteForce

- Time: O((n − m + 1) · m)
- Space: O(m)
