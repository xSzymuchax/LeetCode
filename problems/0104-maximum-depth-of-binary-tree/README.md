# 104. Maximum Depth of Binary Tree

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/maximum-depth-of-binary-tree/)

The depth of a binary tree is the number of nodes on the longest root-to-leaf path.

**Approach:** DFS

- Time: O(n)
- Space: O(h)
