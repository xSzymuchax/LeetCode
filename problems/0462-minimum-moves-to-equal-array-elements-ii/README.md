# 462. Minimum Moves to Equal Array Elements II

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/minimum-moves-to-equal-array-elements-ii/)

One move changes one element by 1. Make every element equal in the fewest moves.

**Approach:** Sorting

- Time: O(n log n)
- Space: O(1) with an in-place sort
