# 2. Add Two Numbers

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/add-two-numbers/)

Two numbers are stored as lists of digits, least significant first. Return their sum in the same form.

**Approach:** LinkedList

- Time: O(m + n)
- Space: O(max(m, n))
