# 2914. Minimum Number of Changes to Make Binary String Beautiful

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/minimum-number-of-changes-to-make-binary-string-beautiful/)

A binary string of even length is beautiful when it can be partitioned into one or more even-length blocks of identical bits. Return the minimum number of bit changes that make it beautiful.

**Approach:** Counting

- Time: O(n)
- Space: O(1)
