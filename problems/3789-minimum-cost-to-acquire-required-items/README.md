# 3789. Minimum Cost to Acquire Required Items

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/minimum-cost-to-acquire-required-items/)

Obtain `need1` items of the first type and `need2` of the second. A purchase is either one item or a bundle of both types.

**Approach:** Greedy

- Time: O(1)
- Space: O(1)
