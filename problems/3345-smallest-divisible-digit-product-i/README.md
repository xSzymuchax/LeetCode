# 3345. Smallest Divisible Digit Product I

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/smallest-divisible-digit-product-i/)

Starting at n, find the smallest integer whose digit product is divisible by t.

**Approach:** BruteForce

- Time: depends on the distance to the answer
- Space: O(1)
