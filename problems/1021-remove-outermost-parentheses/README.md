# 1021. Remove Outermost Parentheses

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/remove-outermost-parentheses/)

The string is a concatenation of primitive valid parenthesis strings. Drop the outer pair of each one.

**Approach:** Counting

- Time: O(n)
- Space: O(n)
