# 3665. Twisted Mirror Path Count

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/twisted-mirror-path-count/)

Move only down or right. A normal cell keeps the direction, and a mirror forces a turn. Count the paths to the bottom-right corner.

**Approach:** DynamicProgramming

- Time: O(mn)
- Space: O(mn)
