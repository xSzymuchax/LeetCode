# 453. Minimum Moves to Equal Array Elements

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/minimum-moves-to-equal-array-elements/)

One move increments n − 1 elements by 1. Make every element equal.

**Approach:** Math

- Time: O(n)
- Space: O(1)
