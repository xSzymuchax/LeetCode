# 3517. Smallest Palindromic Rearrangement I

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/smallest-palindromic-rearrangement-i/)

Rearrange the letters of a palindrome into the lexicographically smallest palindrome.

**Approach:** Counting, Greedy

- Time: O(n)
- Space: O(1) excluding the output
