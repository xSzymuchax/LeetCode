# 37. Sudoku Solver

**Difficulty:** $\textcolor{#dc2626}{\textsf{Hard}}$

[Problem on LeetCode](https://leetcode.com/problems/sudoku-solver/)

Fill the empty cells so the sudoku board stays valid.

**Approach:** Backtracking

- Time: exponential in the number of empty cells
- Space: O(1) excluding the recursion stack
