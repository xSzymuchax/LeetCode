# 3867. Sum of GCD of Formed Pairs

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/sum-of-gcd-of-formed-pairs/)

Prefix GCDs of each value with the running maximum form pairs. Sum the GCDs of those pairs.

**Approach:** Math, Sorting

- Time: O(n log A + n log n)
- Space: O(n)
