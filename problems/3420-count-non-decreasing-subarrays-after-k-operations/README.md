# 3420. Count Non-Decreasing Subarrays After K Operations

**Difficulty:** $\textcolor{#dc2626}{\textsf{Hard}}$

[Problem on LeetCode](https://leetcode.com/problems/count-non-decreasing-subarrays-after-k-operations/)

An operation increments one element by 1. Count the subarrays that can be made non-decreasing at a cost of at most k.

**Approach:** MonotonicDeque

- Time: O(n)
- Space: O(n)
