# 3963. Create Grid With Exactly One Path

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/create-grid-with-exactly-one-path/)

Build an m by n grid with exactly one route from the top-left corner to the bottom-right corner.

**Approach:** Construction

- Time: O(mn)
- Space: O(mn)
