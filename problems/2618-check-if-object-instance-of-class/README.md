# 2618. Check if Object Instance of Class

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/check-if-object-instance-of-class/)

Check whether a value is an instance of the given constructor, including primitives.

**Approach:** Prototype

- Time: O(d) along the prototype chain
- Space: O(1)
