# 1464. Maximum Product of Two Elements in an Array

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/maximum-product-of-two-elements-in-an-array/)

Find two distinct indices that maximize `(nums[i] − 1) * (nums[j] − 1)`.

**Approach:** LinearScan

- Time: O(n)
- Space: O(1)
