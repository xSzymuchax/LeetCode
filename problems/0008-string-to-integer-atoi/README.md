# 8. String to Integer (atoi)

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/string-to-integer-atoi/)

Convert a string to a 32-bit integer: leading spaces, an optional sign, then digits.

**Approach:** Parsing

- Time: O(n)
- Space: O(n)
