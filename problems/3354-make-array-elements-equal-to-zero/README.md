# 3354. Make Array Elements Equal to Zero

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/make-array-elements-equal-to-zero/)

Start on a zero and choose a direction. A move decrements the next positive cell and bounces. Count the starts that clear the array.

**Approach:** PrefixSum

- Time: O(n)
- Space: O(1)
