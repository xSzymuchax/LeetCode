# 17. Letter Combinations of a Phone Number

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/letter-combinations-of-a-phone-number/)

Expand phone keypad digits into every possible string of the mapped letters.

**Approach:** Iteration

- Time: O(4ⁿ · n)
- Space: O(4ⁿ · n)
