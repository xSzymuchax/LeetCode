# 1385. Find the Distance Value Between Two Arrays

**Difficulty:** $\textcolor{#16a34a}{\textsf{Easy}}$

[Problem on LeetCode](https://leetcode.com/problems/find-the-distance-value-between-two-arrays/)

Count elements of the first array for which no element of the second lies within distance d.

**Approach:** BruteForce

- Time: O(n · m)
- Space: O(1)
