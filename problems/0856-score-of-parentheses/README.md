# 856. Score of Parentheses

**Difficulty:** $\textcolor{#ca8a04}{\textsf{Medium}}$

[Problem on LeetCode](https://leetcode.com/problems/score-of-parentheses/)

`()` scores 1, wrapping an expression doubles its score, and adjacent expressions add up.

**Approach:** Counting

- Time: O(n)
- Space: O(1)
